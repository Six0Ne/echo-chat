# 局域网聊天室

## 项目简介
局域网聊天室是一个基于 C++ 的模块化网络通信框架，支持用户管理、消息收发和在线状态维护。通过解耦网络层、事件分发层、连接管理层和协议处理层，提供了高效、可扩展的局域网聊天功能。

## 功能概述

### 用户管理
- **用户注册**：支持 ROOT 用户注册新用户。
- **用户登录**：通过用户名和密码进行身份验证。✅
- **用户登出**：支持用户主动登出。✅
- **删除用户**：ROOT 用户可以删除用户。
- **踢出用户**：ROOT 用户可以强制断开在线用户的连接。
- **查看在线用户**：普通用户可以查看当前在线用户列表。✅

### 消息功能
- **私聊**：支持点对点消息发送，指定目标用户名。 ✅
- **群聊**：支持广播消息给所有在线用户。 ✅
- **系统通知**：包括登录、登出通知等。 ✅
- **消息格式**：
  - 时间戳 + 发送者 + 消息类型 + 内容。 ✅
  - 消息类型包括：登录通知、登出通知、私聊消息、群聊消息、系统消息。 ✅

### 在线状态管理
- 实时维护在线用户列表。✅
- 支持用户上下线通知。✅

## 技术栈

### 编程语言
- **C++17**：使用现代 C++ 特性实现高效的网络通信。

### 网络通信
- **Socket API**：基于 Linux 的套接字编程，支持 TCP 协议。
- **epoll**：高效的 I/O 多路复用机制，用于事件分发。

### 数据结构
- **std::unordered_map**：用于存储用户信息和在线用户列表。
- **std::vector**：用于管理事件和连接。
- **std::mutex**：确保多线程环境下的数据安全。

### 错误处理
- **std::system_error**：用于捕获和处理系统调用的错误。

## 模块解耦

### 1. 网络层（`SocketWrapper`）
- **职责**：
  - 提供对底层套接字操作的封装，包括创建、绑定、监听、连接等功能。
  - 支持非阻塞模式的套接字操作。
- **解耦方式**：
  - 将底层的系统调用封装为独立的工具类，避免上层逻辑直接依赖系统 API。

### 2. 事件分发层（`EventDispatcher`）
- **职责**：
  - 基于 `epoll` 实现事件循环，支持多路复用。
  - 提供事件注册、修改和删除的接口。
  - 分发事件到对应的回调函数。
- **解耦方式**：
  - 使用回调函数将事件处理逻辑与事件分发逻辑分离。
  - 支持动态注册和注销事件处理器。

### 3. 连接管理层（`ConnectionManager`）
- **职责**：
  - 管理所有的客户端连接。
  - 提供添加、移除和获取连接的接口。
  - 支持广播消息到所有连接。
- **解耦方式**：
  - 使用线程安全的数据结构管理连接，避免直接操作连接对象。
  - 将连接的生命周期管理与具体的业务逻辑分离。

### 4. 协议处理层（`ProtocolHandler` 和 `ProtocolDecoder`）
- **职责**：
  - 提供消息的编码和解码功能。
  - 支持自定义协议格式，包括消息头和消息体。
  - 分发解码后的消息到对应的处理器。
- **解耦方式**：
  - 将协议的定义和处理逻辑独立于网络传输逻辑。
  - 使用回调函数将解码后的消息传递给上层逻辑。

### 5. 客户端服务（`ChatClient`）
- **职责**：
  - 提供客户端特定的功能，包括连接服务器、发送消息、接收消息和断开连接。
  - 支持设置连接状态和消息接收的回调函数。
- **解耦方式**：
  - 继承基础网络服务类（`NetWorkService`），复用其事件分发和连接管理功能。
  - 将客户端特定的逻辑与通用的网络逻辑分离。

### 6. 服务器服务（`ChatServer`）
- **职责**：
  - 提供服务器特定的功能，包括监听端口、接受客户端连接和广播消息。
  - 支持自定义连接建立和关闭的处理逻辑。
- **解耦方式**：
  - 继承基础网络服务类（`NetWorkService`），复用其事件分发和连接管理功能。
  - 将服务器特定的逻辑与通用的网络逻辑分离。

## 使用说明

### 编译项目
```bash
mkdir build && cd build
cmake ..
make
```

### 运行客户端
```bash
./char_client 
```

### 运行服务器
```bash
./char_server <IP_ADDRESS> <PORT>
```

## 目录结构
```
src/
  client/               # 客户端代码
  server/               # 服务器代码
  network/              # 网络框架核心模块
    protocol_handler    # 协议处理模块
    connection_manager  # 连接管理模块
    event_dispatcher    # 事件分发模块
    socket_wrapper      # 套接字封装模块
```
